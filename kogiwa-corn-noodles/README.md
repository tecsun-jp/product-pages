# 興宜和KOGIWA ランディングページ

GitHub Pages にそのまま公開できる、スマートフォン向けの静的ページです。ビルド作業は不要です。

## ファイル構成

- `index.html`：ページ内容と4つのリンク
- `style.css`：デザインとスマートフォン対応
- `assets/`：商品写真・Amazon・楽天市場・Mマートのロゴ

## GitHub Pages で公開

1. GitHub で新しい **Public repository** を作成します。
2. このフォルダー内のファイルを、フォルダー構成を保ったまま repository の一番上にアップロードします。
3. repository の **Settings → Pages** を開きます。
4. **Build and deployment** で **Deploy from a branch** を選択します。
5. Branch を **main**、フォルダーを **/(root)** にして **Save** します。
6. 数分後に表示される `https://ユーザー名.github.io/リポジトリ名/` を開きます。

QRコードはこの公開URLに向けて作成してください。リンクだけを変更しても公開URLが同じなら、QRコードを作り直す必要はありません。
